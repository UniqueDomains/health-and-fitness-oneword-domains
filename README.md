## 🧱 Field summary

- `domain`, Fully qualified domain name.

- `renewal_price`, Visible renewal price when available.
- `attractiveness`, Public composite naming band used as a decision-support signal.
- `demand`, Public buyer-pressure band when available.
- `length`, Character count without the TLD.
- `registrar`, Registrar name when known.
- `created_at`, Creation timestamp when known.
- `expires_at`, Expiry timestamp when known.

## ⚠️ Methodology and caveats

This selection groups one-word domain names filtered for health and fitness relevance, drawn from a pool of 171,402 candidates across 506 TLDs. Names range from short, everyday words like tire, complex, and travel to niche terms like punch and acid, each paired with a different extension — from .sh and .studio to .vodka and .catering. With a median ask near $648, the set favors direct comparison between wording, TLD, and price rather than one dominant extension.
